1. Core Pool (2)

Incoming tasks are assigned immediately to available core threads.

2. Work Queue (Cap: 4)

If core threads are busy, new tasks wait in the internal queue.

3. Max Pool (Max: 4)

If the queue fills up, extra threads (up to 4) are spawned to handle the burst.

4. Rejection Policy

If queue is full AND all 4 threads are occupied, tasks are rejected by the executor.
